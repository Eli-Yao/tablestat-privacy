Privacy Policy

Extension: TableStat: HTML Table to LaTeX, CSV & t-Test
Effective Date: November 22, 2026

1. Summary

TableStat: HTML Table to LaTeX, CSV & t-Test processes webpage tables and selected numeric text strictly inside your local browser. We do not collect, transmit, log, or sell personal information, browsing history, or page content.

2. Local In-Browser Computation

  • All HTML table extraction, LaTeX (booktabs, IEEE, APA) generation, CSV/TSV/Markdown formatting, and statistical tests (Mean, SD, 95% CI, Welch's t-test) execute locally on your device.
  • The extension uses the minimal activeTab permission model and runs on a page only when explicitly triggered by you via the toolbar popup, keyboard shortcut, or context menu.

3. Local Preferences Storage

We use chrome.storage.local on your device solely to store export format preferences, pinned sample arrays for two-group comparisons, remaining free Pro trials, and Pro activation status. Nothing in local storage is synced to developer servers.

4. Pro License Verification & Checkout

Optional Pro Lifetime upgrades are processed by independent Merchants of Record (such as Gumroad or Lemon Squeezy). TableStat never receives or stores payment card details. Your TSPRO- license key is verified and stored only on this device. The extension does not contact the merchant to activate it.

5. Zero Analytics & Zero Remote Code

TableStat contains no third-party analytics SDKs, trackers, advertisements, or remotely hosted scripts. All code is self-contained inside the store-reviewed extension bundle.

Questions or support requests can be submitted directly through the official Microsoft Edge Add-ons or Chrome Web Store support tab.
